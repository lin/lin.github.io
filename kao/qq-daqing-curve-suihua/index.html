    大庆Q-Q预测曲线下的绥化一中
    Q-Q 分布预测 · 2004 中考 → 2007 高考

    把绥化一中放到大庆的 Q-Q 预测曲线下

    用大庆市区 2004 中考位次与 2007 黑龙江理科一分一段做 Q-Q 对应：某个中考分数在市区排第几，就假设他在全省高考理科排同等比例的位次，再查一分一段表得到预测高考分。红线即预测。图上每个点是一个班的“第 N 名中考分数 → 第 N 名高考分数”，只看班级整体：点在红线上方，说明该班同名次的高考分数比大庆曲线的预测更高。

    数据：content/kao/qq · 大庆市区 61 档（中考 600–660）· 高三三班（高考≥600）· 高三一班前五

    参考名次线：清华 687 / 北大医学部 674 / 上海交大 665 / 南京大学 653 / 上海财经大学 640

    高考分先按 2007 理科一分一段表换成全省位次，再用大庆曲线反查所需中考分。分科预测不够准，分科图上不画这三条线。

    分科 Q-Q：用中考预测理综、数学、语文、英语，以及数语外之和

    中考分 → 大庆市区位次 → 对应的全省高考位次 → 鹤岗应届前 100 名里“该位次附近的该科成绩”。做法：鹤岗 89 人按总分的全省位次从小到大排，某一科单独从高到低排，第 i 个位次对第 i 高的成绩，形成位次到该科成绩的 Q-Q 对应；位次之间按对数位次线性内插。青点是三班已知的单科成绩。“数语外”一图把每人的语文+数学+英语相加后，再单独排序做 Q-Q（红线）；虚线是三科各自曲线直接相加，作为对照。

    怎么读、别读过头

    • 主图横轴从中考 604 起（红线在这里已接近高考 640），纵轴保留全部三班点。线性简化线只针对高考≥640 的区间（中考 606–660）对红线做最小二乘：高考分 ≈ 1.2776 × 中考分 − 136.23，R² = 0.995，比原表“线性简化分”那条 1.2101 的直线更贴红线；这一段的预测相对更可靠。
    • 曲线是大庆市区的“中考位次 → 全省高考位次”映射，不是绥化的映射。
    • 每个点是一个班的 Q-Q 点：第 N 名的中考分数，对应同一个班高考第 N 名的分数。点里没有具体的人，两个分数各自单独排序。比如中考第三的分数，去预测该班高考第三的分数。曲线上的预测是用同一个中考分数查大庆曲线得到的。
    • 三班拟合线只用中考<630 的名次点，并延长到第 1 名的点，斜率明显比曲线陡：两个分数各自排序后必然同增同减，Q-Q 点天然近似单调，R² 很高不说明中考预测了高考；它的用处是看整体比曲线低多少、斜率差多大。
    • 分科曲线用的是鹤岗应届前 100 名的单科排序，不是全省的单科分布；只覆盖全省位次约 9–3637，且单科在总分附近波动很大，曲线只反映鹤岗这 89 人。三班的点是给定的已知值，每科只有两三个，只看它们和曲线的大致关系。
    • “一班全部”里除前五名外的高考分是从原区间取中点得到的猜测值，空心菱形表示；这些点只反映区间中点，不能当作个人成绩。图上只画高考≥600 的点（共 38 个名次）。
    • 两个班的中考分都是推断值，只看整体相对曲线的位置，个体得失没有意义。三班只含高考≥600 的 46 人，一班为前五名。
    • 高三一班的中考分是“按高考排名”倒推出来的，本身就来自同一条 Q-Q 关系，所以差值接近 0 是构造使然，只能说明倒推自洽，不是独立验证。
    • 高三三班的中考分多为 copula 重排的估计，已知的极少，逐名次的差值噪声很大；看整体均值和走势更可信。
    • 只取高考≥600 的样本，是对高考分数的截断，会使差值均值偏正；不能据此断言绥化一中“超预期”。
    • 预测取值在中考 600–660 内插值；范围外的点不画。
